# cams/ru — база камер для России

`cams.bin` — компактная база камер для HUD (формат — [docs/cams_format.md](../../docs/cams_format.md)).

## Источник

Открытая база [openSpeedcam.net](https://openspeedcam.net), формат 7Ways+ extended+ (`7Ways+_RU.txt`).
Её ведёт сообщество энтузиастов, камеры добавляют пользователи, скачивание свободное.

В `cams.bin` попадают только камеры: 192, 194 — стационарные; 215 — посты ДПС; 193 — мобильные; 199 — камеры полосы.

Знаки, пешеходные переходы, лежачие полицейские и прочие точки в `cams.bin` не попадают.

## Как собрано

```
python3 tools/gen_cams.py 7Ways+_RU.txt -o cams.bin
```

Формат входного файла определяется автоматически. Подробности — в [docs/cams_format.md](../../docs/cams_format.md).

## Ограничения

Данные сообщества могут содержать неточности и устаревшие записи. Направление камер (`Direction`) взято из базы как есть и на местности проверено не полностью.

База не обновляется автоматически: при желании собери свежий `cams.bin` сам по команде выше.
