# cams/ru — база камер для России

`cams.bin` — компактная база камер для HUD (формат — [docs/cams_format.md](../../docs/cams_format.md)).

## Источник

Открытая база [openSpeedcam.net](https://openspeedcam.net), формат 7Ways+ extended+ (`7Ways+_RU.txt`).
Её ведёт сообщество энтузиастов, камеры добавляют пользователи, скачивание свободное.

В `cams.bin` попадают только камеры: 192, 194 — стационарные; 13 — скорость плюс контроль разметки; 12 и 203 — скорость «сзади» и светофор + скорость (признаки 1 и 2); 215 — посты ДПС; 193, 209 — мобильные; 199 — камеры полосы; 227 — начало средней скорости.

Знаки, пешеходные переходы, лежачие полицейские и прочие точки в `cams.bin` не попадают.

## Как собрано

```
python3 tools/gen_cams.py 7Ways+_RU.txt 7Ways+_BL.txt -o cams.bin
```

Формат входного файла определяется автоматически. Подробности — в [docs/cams_format.md](../../docs/cams_format.md).

## Ограничения

Данные сообщества могут содержать неточности и устаревшие записи. Направление `Direction` в 7Ways+ — это направление «на камеру»: конвертер по умолчанию поворачивает его на 180° (`--w7-dir-offset`), так курс в `cams.bin` совпадает с курсом проезжающих. Камера на одной опоре, которая снимает обе стороны, записана двумя записями с курсами через 180°.

Ложные для вашего маршрута камеры можно убрать по координатам: `--exclude tools/cams_exclude.txt` (строка `lat, lon [радиус_м]`, по умолчанию 15 м).

База не обновляется автоматически: при желании собери свежий `cams.bin` сам по команде выше.
